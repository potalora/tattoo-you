# Editor-first placement journey

The approved brief is an editor-first Instrument studio covering setup, placement, adjustment, visual comparison and reference review. Desktop and phone are equal acceptance targets. The body and artwork lead; concise contextual guidance supplies the next useful action without a compulsory wizard.

## Interaction contract

- Keep one renderer and the existing study, storage, history, artwork and backup formats. Preserve original artwork bytes and independent alternative studies.
- Separate selected-tattoo controls, the tattoo collection and study actions. The collection is independently reachable; choosing a tattoo reveals its adjustments. Phones use compact Place / Size / Rotate / View / More tools and an expandable deck for deeper work.
- Empty studies offer Reference → Artwork → Placement. Reference anatomy/profile precede detailed shape controls. Import opens a useful close-up with placement guidance; all editor controls remain available.
- Comparison captures two compatible body studies using one camera pose. Desktop shows paired views; phones switch A/B at the same scale. Captures never replace either study or its saved camera, and the live renderer is restored before editing resumes.
- Reference review displays the exact generated PNG with its caption. Download uses those same bytes; direct export remains available. Returning to editing supports another angle without inventing PDF or automatic multi-view export.

## Implementation and acceptance

1. Test and build isolated comparison and reference preparation workflows.
2. Restructure Instrument hierarchy, setup and contextual editing; preserve Glass compatibility.
3. Integrate protected comparison/reference states with loading, error and return routes.
4. Build, run domain and interface checks, inspect generated runtime parity.
5. Verify empty/import/place/adjust/multiple selection/locks/alternatives/comparison/reference/download/reload on desktop, phone portrait and landscape. Review long names, errors, keyboard focus and reduced motion. Use original demo artwork only.

Impeccable flows applied: shape (the user-approved brief), layout, distill, adapt, onboard, clarify and polish. Independent critique established the spatial problem before implementation; the pre-edit layout detector returned no findings. A clean detector does not establish a good hierarchy.

Publication is outside this implementation task. Deliver an isolated working preview and verified changes for review.

## Accepted implementation

The completed preview retains the opaque, tactile Instrument direction: recessed display, solid control deck, raised keys and orange selection accents. The complete five-part journey passed desktop and phone browser checks. Final checks resolved narrow study-name identification, stale numeric validation, review return focus, and the camera bank's use of phone canvas space.

Validation: 645 tests passed; the public build and generated UI parity checks passed. Independent source review found no actionable blockers. Desktop and phone PNG downloads matched the reviewed images byte for byte. Browser checks used original demo artwork and isolated origins; physical devices and Safari remain untested. Detailed local evidence is retained in `output/editor-journey/acceptance.md`.
